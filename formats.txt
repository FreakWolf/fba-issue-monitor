    T: Program Problem

    Group: Amazon Easy Ship Program

    T: Shipping Claims
    I: Fees Escalations
    Group: T4 Credit Ops Project IN

are ignored to avoid false positives.

EF CHANNEL - SAFE-T ESCALATIONS (EasyShip / Seller Flex / MFN)
================================================================================

These are External Fulfillment channel SAFE-T escalation tickets.
Assignment is based on Yoda dashboard lookup (Channel + Final Resolution).

Yoda Dashboard: https://yoda-insights.corp.amazon.com/drag-n-drop/view-dataset?dashboardId=7d97f3d6-275a-42ef-83eb-fd2c96e49271

Steps:
  1. Open Yoda → click "SAFET Raw for all Channels" tab
  2. Expand Controls → Enter Order IDs in the Order ID filter
  3. Check results: Channel column + Final Resolution column
  4. Majority Channel determines MFN vs EasyShip/SellerFlex
  5. Majority Final Resolution determines assignee

AUTO-MODE BEHAVIOR
================================================================================

When Auto Mode is enabled, the extension runs every 5 minutes and:

  1. Scans unassigned tickets in the Reimbursements India queue
  2. Classifies each ticket
  3. For each ticket, takes action automatically:

     a. Weight/Dimension/Fees → Auto-resolve with out-of-scope comment
     b. EF Channel (EasyShip/SellerFlex/MFN + SAFE-T):
        - Extract Order IDs from ticket
        - Open Yoda dashboard (background tab)
        - Enter Order IDs, scrape Channel + Final Resolution
        - Determine assignee from majority values
        - Auto-assign to correct owner
     c. Wiki Not Followed (missing mandatory fields) → Auto-resolve with template
     d. Classified + All Fields Present → Auto-assign to designated owner

  No manual intervention required. Chrome must be running.
